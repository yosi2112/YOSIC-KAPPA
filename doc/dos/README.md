# KAPPA DOS

KAPPA CPU上で動くDOSです。FAT12のファイル操作、4ドライブ、8つの内蔵コマンド、独自形式`YKE1`・独自拡張子`.YKE`の外部プログラムに対応します。

- [DOS説明書](manual.md)：起動・操作・保存、ディスク、実行形式、システムコール、ファイルハンドル。
- [コマンドリファレンスマニュアル](commands.md)：内蔵8コマンドと外部プログラムの書式・例・エラー。
- [ビルド・開発用マニュアル](../build.md)：ソースからのビルドと開発作業。

本ディレクトリではDOSの利用方法と技術仕様を説明します。ビルド方法は扱いません。
