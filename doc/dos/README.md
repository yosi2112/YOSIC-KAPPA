# YOSIC-DOS 1.0K

KAPPA CPU上で動くDOSです。FAT12のファイル操作、4ドライブ、9つの内蔵コマンド、独自形式`YKE1`・独自拡張子`.YKE`の外部プログラムに対応します。

- [DOS説明書](manual.md)：起動・操作・保存、ディスク、実行形式、システムコール、ファイルハンドル。
- [コマンドリファレンスマニュアル](commands.md)：内蔵9コマンドと外部プログラムの書式・例・エラー。
- [ビルド・開発用マニュアル](../build.md)：ソースからのビルドと開発作業。
- [システム媒体と連携操作](system-media.md)：5コマンド入り媒体、編集・コンパイル・一括実行、SYSによる起動領域の転送。
- [LEDT説明書](ledt.md)：行単位の編集、分割読込み、保存とバックアップ。
- [PL/DULL説明書](pldull.md)：言語、コンパイル、生成プログラムのファイル操作。

本ディレクトリではDOSの利用方法と技術仕様を説明します。ビルド方法は扱いません。
