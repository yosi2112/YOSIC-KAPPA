# YOSIC-DOS 1.0Kコマンドリファレンスマニュアル

## 共通規則

プロンプトは`0:>`〜`3:>`です。内蔵コマンド名とファイル名は大小文字を区別しません。パスも同じ番号の`0:`〜`3:`を使用し、英字のドライブ表記は受け付けません。相対パスは指定ドライブ（省略時は選択中のドライブ）のカレントディレクトリ基準です。先頭の`\`はルートを指定します。現在位置はドライブごとに保持し、起動時はすべてルートです。名前は8.3形式、区切りは`\`です。入力は最大127バイトです。

`[ ]`は省略可能な引数を表す説明用の記号です。各内蔵コマンドは単独の`/?`引数で書式を表示します。MD/RD/DELなどの短縮別名はありません。`1:`単独のドライブ切替、CD、BAT、パイプ、リダイレクト、環境変数、PATHには対応していません。

## DIR — 一覧表示

```text
DIR [path] [/B]
```

指定パスのファイル・ディレクトリを表示します。省略時はカレントドライブのカレントディレクトリです。通常はファイルサイズまたは`<DIR>`を併記し、`/B`では名前だけを出力します。`*`は名前・拡張子の残り、`?`は1文字に一致します。

```text
DIR
DIR 0:\TOOLS\*.YKE /B
DIR /?
```

## MKDIR — ディレクトリ作成

```text
MKDIR path
```

ディレクトリを1つ作成します。親は先に作成してください。同名の項目がある場合、空きクラスタ・ディレクトリ項目が不足する場合は拒否します。

```text
MKDIR TOOLS
MKDIR TOOLS\DATA
```

## RMDIR — ディレクトリ削除

```text
RMDIR path
```

空のディレクトリを削除します。ルート、現在使用中のディレクトリ、通常ファイル、内容が残るディレクトリは拒否します。再帰削除には対応しません。

```text
RMDIR TOOLS\DATA
```

## DRIVE — カレントドライブ変更

```text
DRIVE [0|1|2|3]
```

引数なしでは現在の番号を`0:`〜`3:`として表示します。番号を指定すると選択を変更し、次のプロンプトも変更します。`DRIVE 1`はドライブ1を選択します。

```text
0:>DRIVE 1
1:>DRIVE
1:
1:>
```

引数は0〜3の1桁だけです。`A:`、`1:`、`01`、`-1`、`4`は無効です。切替時に媒体とFAT12情報を確認し、未接続・不正媒体ではエラーを表示して元のドライブを維持します。

## CHDIR — カレントディレクトリ表示・変更

```text
CHDIR [path]
```

引数なしでは現在位置を`0:\TOOLS`のように表示します。パスを指定すると、存在するディレクトリへ変更します。`.`は現在位置、`..`は親、`\`はルートを表します。ファイル、ワイルドカード、存在しないパスは拒否し、失敗時は元の現在位置を維持します。正規化後のパスは63文字以内です。

ドライブ付きのパスは、そのドライブの現在位置だけを変更します。`CHDIR 1:`はドライブ1の現在位置を表示します。カレントドライブを切り替えるには`DRIVE 1`を使います。プロンプトはドライブ番号だけを表示します。`CD`の短縮別名と`/D`オプションはありません。

```text
CHDIR TOOLS
CHDIR
CHDIR ..
CHDIR \
CHDIR 1:\DATA
CHDIR 1:
DRIVE 1
```

## COPY — ファイルコピー

```text
COPY source destination [/Y]
```

ファイルをバイナリのままコピーします。空ファイル、別ドライブ、既存ディレクトリ宛てに対応します。宛先に同名ファイルがある場合は確認し、`/Y`で確認を省略します。元と同じファイルへのコピーは拒否します。ディレクトリ自体のコピーには対応しません。

複数の一致を持つsourceでは、destinationに既存ディレクトリを指定します。コピー元は`*`・`?`で絞り込めます。

```text
COPY HELLO.YKE 1:\HELLO.YKE
COPY *.YKE TOOLS /Y
COPY DATA.BIN BACKUP.BIN /Y
```

## MOVE — 移動・名前変更

```text
MOVE source destination [/Y]
```

単一のファイルまたはディレクトリを移動・名前変更します。同一ドライブではデータクラスタを保持します。別ドライブのファイルではコピー成功後に元を削除します。宛先が既存ディレクトリなら、その中へ移動します。

既存の同名宛先、現在使用中のディレクトリやその親の移動・名前変更、ディレクトリを自分の子へ移す操作、別ドライブへのディレクトリ移動は拒否します。上書き・再帰・ワイルドカード指定はありません。

```text
MOVE OLD.YKE NEW.YKE
MOVE NEW.YKE TOOLS
MOVE DATA.BIN 1:\DATA.BIN
```

## DELETE — ファイル削除

```text
DELETE path [/P]
```

一致する通常ファイルを削除し、使用クラスタを解放します。`*`と`?`に対応します。`/P`ではファイルごとに確認します。全ファイル指定では一括削除の確認も行います。ディレクトリは削除せず、読取り専用属性のファイルは拒否します。

```text
DELETE OLD.YKE
DELETE TOOLS\*.YKE /P
```

## SYS — KAPPA起動システム転送

```text
SYS 1:|2:|3:
```

ドライブ0のKAPPA起動システムをドライブ1〜3へ転送します。転送元はカレントドライブに関係なく0です。転送先の既存ファイルを保持します。ドライブ0への転送は拒否します。

転送先はDOS対応FAT12媒体で、書込みが許可されている必要があります。通常のLBA0 FAT12媒体では、起動領域を確保するためFAT・ディレクトリ・使用中データを移し、ラベル・シリアル・ファイル内容を保持します。移せない使用中クラスタが媒体末尾にある場合、書込み開始前に容量不足で拒否します。既にKAPPA起動形式の媒体にも再転送できます。

```text
SYS 1:
```

成功時は`System transferred`と表示します。保存した転送先媒体から起動する場合は、それをエミュレータのドライブ0に接続します。SYSはYKEファイルのコピーコマンドではありません。

## 外部プログラム — .YKE実行

```text
path[.YKE] [argument tail]
```

内蔵コマンドと一致しない最初のトークンを実行パスとして解釈します。拡張子省略時は`.YKE`を補います。明示する拡張子は`.YKE`だけを受け付けます。検索場所は指定パスまたは選択ドライブのカレントディレクトリです。内蔵名と競合する場合は、拡張子やパスを明示します。

```text
HELLO
hello.yke
1:\TOOLS\HELLO.YKE MiXeD "argument"
"0:\TOOLS\HELLO.YKE" argument
DIR.YKE
```

ファイルには独自`YKE1`ヘッダとKAPPA CPU命令が必要です。実行前にサイズ・ヘッダ・入口・チェックサム・FATチェーンを検証します。引数末尾の大小文字と引用符は保持し、個別の引数解釈はプログラム側に委ねます。復帰規約とファイル形式は[DOS説明書](manual.md#6-yke1実行ファイル形式)を参照してください。

## 主なメッセージ

| 表示 | 意味・対処 |
|---|---|
| `File or path not found` | ファイルや親ディレクトリがない。パス・ドライブ・拡張子を確認 |
| `Invalid YKE executable` | 拡張子、サイズ、YKE1ヘッダ、入口またはチェックサムが不正 |
| `Cannot remove current directory` | カレントディレクトリを削除しようとした。先に別の場所へCHDIRする |
| `Access denied` | 禁止対象、読取り専用属性、非空ディレクトリなど。対象と操作を確認 |
| `Invalid drive specification` | ドライブ表記やDRIVEの番号が無効 |
| `Drive not ready` | 媒体が接続されていない、または準備できない |
| `Write protect error` | 書込み不可。対象ドライブの保存設定を確認 |
| `Invalid parameter` | 引数・オプション・引用符などの書式が不正 |
| `Invalid disk or data error` | BPB、FATチェーン、FDC転送などが不正 |
| `Insufficient disk space` | クラスタやディレクトリ項目、SYS用領域が不足 |
| `Duplicate file name or file not found` | 同名の項目が存在する、または一致する対象がない |
| `File cannot be copied onto itself` | コピー元とコピー先が同じ |
| `Path too long` | 正規化後のパスが長すぎる |
| `Input line too long` | 入力が127バイトを超えた。短くして再入力 |
| `Invalid input byte` | 入力にNULが含まれる |

成功時に表示がないコマンドもあります。プログラムの終了コードとコマンド結果は内部に記録されますが、表示・条件分岐を行うコマンドはありません。

## FORMAT.YKE

`FORMAT drive: [/F:1440|1232] [/Q] [/Y]` は0:〜3:のFDをデータディスクとして初期化します。1440KiBは80×2×18×512、1232KiBは77×2×8×1024です。通常は全トラックを物理初期化し、BPB・FAT2面・空ルートを作成します。起動ペイロードは作成しません。システム媒体には別途SYSを使用してください。

読めないBPBには `/F` が必要です。読める物理IDと指定プロファイルが異なる場合は拒否します。`/Q` は既存BPBの幾何が一致する場合に管理領域だけを初期化し、データ領域を保持します。`/Y` がなければ対象ドライブを表示してYで確認します。それ以外の応答は無変更で終了します。Ctrl+Cはトラック境界で中断します。開始後の中断や転送失敗では既に初期化された部分は戻りません。

書込み禁止、媒体なし、不正指定はエラー終了します。`Media error` の数値は19=保護、21=未準備/タイムアウト、23=幾何/データ、87=引数、995=中断です。エラー後は媒体を確認し、必要なら明示したプロファイルで再実行してください。HDと64bit高位LBAは内部境界で書込み前に拒否します。

## DISKCOPY.YKE

`DISKCOPY source: target: [/Y]` は0:〜3:の同じ幾何のFDを、空き領域を含む全物理セクタ単位で複製します。1トラックをRAMへ読み、先を初期化して書込み、別バッファへ再読取りして全バイトを比較します。コピー元には書き込みません。先が読める異幾何なら拒否し、適合する未初期化先は元のプロファイルでFORMATします。D88/KFDのコンテナ情報、弱セクタ等の完全再現は対象外です。

同一ドライブは元を入れて開始し、`Insert TARGET` で先へ、`Insert SOURCE` で元へ交換してEnterを押します。`/Y`でも交換確認は省略しません。モニタへCtrl+Breakで戻り、`DT 1` と `AT 1 "target.kfd"` で書込み先を、`AT -R 1 "source.d88"` で元を接続し、G後Enterで続行できます。新規KFDはATの既定形状で作成されるため、1232KiBの新規媒体には起動時 `--geometry 77 2 8 3` が必要です。初期化後の回転配置を保つため書込み先はKFDを推奨します。

交換ごとに幾何と書込み保護を確認します。Ctrl+Cで中断できますが、書込み済みトラックは戻しません。媒体の内容が同じ場合や誤って同じ媒体を戻した場合を完全に識別する機構はありません。対象表示と媒体の管理は操作者が確認してください。

## SUBMIT.YKE

`SUBMIT file[.SUB] [arg1 ... arg9]` はテキスト中のコマンドを展開して投入します。`$0`は指定したファイルトークン、`$1`〜`$9`は引数、欠落引数は空文字、`$$`はドル記号です。置換は1回だけで、引数中のドル記号は再展開しません。ASCII英字を大文字化し、`^A`〜`^Z`を制御文字1〜26へ変換します。引用符による引数拡張はありません。不正なドル・制御表記、NUL、行125バイト超過、展開データと行長の合計2048バイト超過は行番号付きエラーになります。

CR、LF、CRLF、Ctrl+Z、物理EOF、末尾改行なしを扱い、空行は無視します。展開全体を検証してから `0:\$$$.TMP` に最後の行から逆順の128バイトレコードを書き、全ハンドルを閉じて通常の `MOVE /Y` で `0:\$$$.SUB` へ置換します。入力の予約名との衝突を防ぐため、末尾ファイル名 `$$$.SUB` / `$$$.TMP` は入力として拒否します。一時出力の作成・書込み失敗では既存投入を維持します。

DOSは起動時とコマンド境界に0:ルートの投入ファイルを検出します。サイズ、属性、FATチェーン、末尾レコードを検証し、実行するレコードを先に削り、不要クラスタを解放してからコマンドを表示・実行します。最後のレコードは実行前にファイルごと削除します。消費を保存できなかった行は実行しません。形式不正、内蔵コマンド・ロード失敗、外部プログラムの非0終了では後続を破棄します。破棄失敗は表示し、自動再実行を抑止します。媒体を確認・修復して予約ファイルを削除し、Ctrl+Cで再ログインしてください。完全な電源断耐性は保証しません。

別のSUBMITは残りの投入を置き換え、元の投入へ戻りません。末尾での連鎖を推奨しますが、途中での置換も可能です。Ctrl+Cとコマンド境界のキーは投入を中断します。YKEのGETCHARは実際のコンソールを読み、投入の行を対話入力に流用しません。アプリのファイルハンドルは次のアプリへ持ち越しません。

CP/M原典の「逆順レコードを作るSUBMITと、末尾を実行前に消費するCCP」の役割分担を引き継ぎます。原典の大文字化と小文字aを減算する制御文字変換の不整合、末尾CR依存、長さの端点は移植上の意図を優先して上記仕様へ統一しました。生成・消費とも0:ルートへ固定し、現在ドライブとCCPの参照先が異なる配置問題を避けています。外部非0終了での停止はKAPPAの拡張です。

`MOVE source destination /Y` は既存の通常ファイルを上書きできます。読取り専用対象・ディレクトリの置換・破損/交差チェーンは拒否します。同一ドライブでは元データのクラスタを引き継ぎ、旧宛先のチェーンを解放します。同じディレクトリセクタ内の置換は1回のディレクトリ更新で公開します。`/Y`なしの既存宛先拒否は従来どおりです。

## LEDT.YKE

`LEDT filename [/B]` はEDLIN形式のラインエディタです。行番号、`.`、相対位置、`#`、I/D/L/P、確認付きS/R、反復C、M、Tを扱います。Ctrl+Zだけの行で挿入を終えます。通常はファイル内のCtrl+Zが入力終端で、`/B`では本文として保持します。出力の改行はCRLFです。

Aは元ファイルの未読部分を約75%まで追加し、Wは先頭行を一時ファイルへ書いて成功した行だけを除きます。Eは残る本文と未読末尾を保存し、元をBAKへ退避して一時ファイルを元の名前へ切り替えます。既存BAK・一時名との衝突は拒否します。Qは確認後に破棄し、W後も元ファイルを変えません。全構文、容量、保存失敗時の復旧は[LEDT説明書](ledt.md)を参照してください。
