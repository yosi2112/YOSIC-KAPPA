# PL/DULL — KAPPA用ネイティブコンパイラ

PL/DULLはPascalに似た小規模な整数言語です。`DULL.YKE`がDOS上でソースを解析し、KAPPA命令を含む通常のYKE1実行ファイルを生成します。生成したプログラムはDULLを含まない媒体でも実行できます。

## 使い方

```text
DULL source [output] [/A|/L]
```

`source`は拡張子を含めて指定します。省略時の出力名は入力パスの末尾の拡張子を`.YKE`、`/A`では`.ASM`、`/L`では`.LST`へ置き換えたものです。拡張子がなければ付加します。出力を明示した場合はその名前を使います。DOSから実行するバイナリの拡張子は`.YKE`にしてください。

```text
DULL HELLO.DUL
HELLO
DULL HELLO.DUL HELLO.ASM /A
DULL HELLO.DUL HELLO.LST /L
```

`/A`は生成命令とデータを`DD`で表すKAPPA ASMです。再アセンブルすると通常出力のYKEペイロードと一致します。`/L`は生成オフセット、32bit語、ソース行番号の一覧です。ランタイムの行番号は0です。ヘッダのないASM/LST自体をDOSから実行することはできません。

オプションは出力名の前後どちらにも置けます。`/A`と`/L`の併用、重複オプション、空の引数、余分な引数はエラーです。パスはDOSのドライブ番号・カレントディレクトリ・8.3形式に従います。入力は63文字、出力は60文字までです。空白を含むパスは使えません。

## 字句と全文法

予約語と識別子はASCII英字の大小を区別しません。識別子は英字で始まり、以後は英数字だけを使います。`#`から行末まではコメントです。数値は符号のない10進トークンで、負数は単項`-`で表します。文字列は二重引用符で囲み、エスケープや文字列内改行はありません。Shift-JISを含む文字列のバイトは変換せず保持します。表示には対応する端末が必要です。

```text
プログラム = PROGRAM ";" { 変数宣言 | 関数宣言 } BEGIN 文列 END "."
変数宣言   = VAR 識別子 { "," 識別子 } ";"
関数宣言   = FUNCTION 識別子 [ 引数宣言 ] ";"
             { 変数宣言 } BEGIN 文列 END ";"
引数宣言   = "(" 識別子 { "," 識別子 } ")"
文列       = 文 { ";" 文 }
文         = [ 代入 | 関数呼出し | 組込み呼出し
             | BEGIN 文列 END
             | IF 式 THEN 文 [ ELSE 文 ]
             | WHILE 式 DO 文 ]
代入       = 識別子 ":=" 式
関数呼出し = 識別子 [ "(" 式 { "," 式 } ")" ]
式         = 和 [ ( "=" | "<>" | "<" | "<=" | ">" | ">=" ) 和 ]
和         = 項 { ( "+" | "-" ) 項 }
項         = 要素 { ( "*" | "/" | "%" ) 要素 }
要素       = [ "-" ] ( 数値 | 識別子 | "(" 式 ")"
                      | 関数呼出し | 組込み呼出し )
組込み呼出し = WRITE [ "(" 引数 { "," 引数 } ")" ]
             | WRITELN [ "(" 引数 { "," 引数 } ")" ]
             | GET | BREAK | CONTINUE
             | FOPEN "(" 文字列 "," 式 ")"
             | FCLOSE "(" 式 ")" | FGETC "(" 式 ")"
             | FPUTC "(" 式 "," 式 ")" | FEOF "(" 式 ")"
             | FWRITE "(" 式 { "," 引数 } ")"
             | FWRITELN "(" 式 { "," 引数 } ")" | IORESULT
引数       = 式 | 文字列
```

セミコロンは文の区切りです。空文と末尾のセミコロンを許します。`ELSE`は最も近い`IF`に結び付きます。条件は0が偽、非0が真です。`BREAK`は最内側の`WHILE`を抜け、`CONTINUE`はその条件判定へ戻ります。ループ外では使用できません。

## 変数・関数・整数

グローバル変数は起動時に0で初期化します。関数には値渡しの引数、ローカル変数、暗黙のローカル変数`RESULT`があります。戻り値は`RESULT`へ代入します。ローカル変数と`RESULT`は必ず代入してから読み、その前の値に依存しないでください。

引数は左から右へ評価します。0引数関数は括弧なしで呼びます。関数名を本体の解析前に登録するため自己再帰が可能です。参照できる関数は自分自身と先に宣言済みのものだけです。入れ子の関数宣言、前方参照、配列、文字列変数はありません。ローカル変数は外側の名前を隠せますが、同じスコープの重複と自分の関数名の再宣言はエラーです。

整数は16bitです。定数、加減乗算、単項負号、代入は低位16bitに折り返します。比較と十進表示は符号付きの`-32768`〜`32767`として扱い、比較結果は1または0です。除算の商は0方向へ丸め、余りは被除数と同じ符号になります。`-7/3`は`-2`、`-7%3`は`-1`です。0除算と`-32768/-1`は実行時エラーになります。

## コンソール入出力

`WRITE`は文字列と整数を順に表示し、`WRITELN`は最後にCRLFを表示します。区切りの空白は自動挿入しません。両命令を式として書いた場合の結果は0です。文字列はこれらの表示引数、FWRITE/FWRITELNの表示引数、FOPENのパスで使えます。文字列変数や文字列を一般の式に使う機能はありません。

`GET`は数字・Backspace・Enterで編集する整数入力です。1桁以上入力してEnterを押すと値を返します。符号や他のキーは無視します。255桁まで入力でき、値は16bitに折り返します。Backspaceは折返し前も含めて入力した接頭辞の値へ戻ります。CR、LF、CRLFと連続したGETを扱います。

## 原典の四つの例

以下は原典の例をKAPPA版でも使える形で示したものです。

### Hello World

```text
program;
begin
    writeln("Hello World");
end.
```

### 四則演算と余り

```text
program;
var left,right;
begin
    write("左辺の値>"); left := get;
    write("右辺の値>"); right := get;
    writeln(left, "+", right, "は、", left+right);
    writeln(left, "-", right, "は、", left-right);
    writeln(left, "÷", right, "は、", left/right);
    writeln(left, "×", right, "は、", left*right);
    writeln(left, "÷", right, "の余りは、", left%right);
end.
```

7と3を入力すると、結果は順に10、4、2、21、1です。

### 余りによる数当て

```text
program;
function GetValue(max);
begin
    write(max,"で割った余りは？>");
    result := get;
    while (result<0)+(result>=max) do
    begin
        write("範囲外です。>");
        result := get;
    end;
end;
var mod7,mod5,mod3,x;
begin
    writeln("0から104までの整数を1つ考えて下さい。");
    writeln("その数に対して 3つの質問をします。");
    mod3 := GetValue(3);
    mod5 := GetValue(5);
    mod7 := GetValue(7);
    x := (15*mod7 + 21*mod5 + 70*mod3) % 105;
    writeln("あなたの考えた数は、",x,"でしょう！");
end.
```

余りを0、2、0と入力すると42になります。

### 再帰ハノイ

```text
program;
function Hanoi(n,A,B,C);
begin
    if n>0 then
    begin
        Hanoi(n-1,A,C,B);
        writeln(n,"番の円盤を棒",A,"から棒",B,"へ移動");
        Hanoi(n-1,C,B,A);
    end;
end;
var n;
begin
    write("nの数>");
    n := get;
    Hanoi(n,1,2,3);
end.
```

3を入力すると7回の移動を表示します。この例は関数の戻り値を使用しないため、`RESULT`へ代入していません。

## ファイル操作

以下はKAPPA版の拡張予約語です。変数名・関数名・仮引数名には使えません。各呼出しは単独文と式の両方で使えます。引数は左から右へ評価します。

| 呼出し | 結果 |
|---|---|
| `FOPEN("path",mode)` | 成功はハンドル1〜8、失敗は0 |
| `FCLOSE(handle)` | 成功0、失敗はDOSエラー番号 |
| `FGETC(handle)` | 1バイトの0〜255、EOFまたは失敗は-1 |
| `FPUTC(handle,value)` | 1バイトを書込み、成功0、失敗はDOSエラー番号 |
| `FWRITE(handle [,値または文字列...])` | 連結して書込み、成功0、失敗はDOSエラー番号 |
| `FWRITELN(handle [,値または文字列...])` | FWRITEの後にCRLFを書込む。結果は同じ |
| `FEOF(handle)` | 直前までにEOFへ到達した有効ハンドルなら1、それ以外0 |
| `IORESULT` | 最後のファイル操作のDOSエラー番号。括弧なし |

パスは最大63バイトの文字列リテラルで、DOSの8.3形式・番号ドライブ規約に従います。動的パス、削除・名前変更・SEEKはありません。`mode`は式で指定し、0=既存読取り、1=作成または既存内容の切詰め書込み、2=既存読書きです。どのモードも先頭位置から開始します。**モード2は追記ではなく**、読み終えた位置から書くとその部分を上書きします。

`FGETC`はNUL、1Ah、FFhも通常のデータとして返します。成功したREADの転送量が0の場合だけ通常EOFとし、`FGETC=-1`、`FEOF=1`、`IORESULT=0`になります。READ失敗では`FGETC=-1`、`IORESULT`にエラーを記録し、EOF状態を新しく立てません。OPEN成功、1バイト取得、WRITE成功でEOF状態を0へ戻します。

`IORESULT`の初期値は0で、成功または通常EOFで0になります。参照しても値は消えません。有効な`FEOF`照会も値を変更しません。無効・解放済みハンドルの照会は0を返し、`IORESULT=6`になります。二重CLOSEや1〜8以外のハンドルもエラー6です。媒体交換でDOSがエラー6を返したハンドルはランタイムでも失効します。開けるファイルは同時8個までで、同じファイルの重複OPENはDOSの規則に従って失敗します。

`FPUTC`の値は0〜255に限定し、範囲外は87です。`FWRITE`系の整数は符号付き十進表記で、空白は自動挿入しません。`FWRITE(h)`は空出力、`FWRITELN(h)`は改行だけです。最初の失敗または短いWRITEで処理を止め、後続引数を評価せず、残りの文字と改行も出力しません。既に書いた部分は残ります。容量不足または成功扱いの短いWRITEは112として報告します。

ファイルエラーは自動終了せず、呼出し元が戻り値と`IORESULT`で処理します。正常終了と実行時エラーのどちらでも、ランタイムが開いたハンドルを解放します。この終了処理は直前の`IORESULT`を上書きしません。ファイル処理は既存のOPEN/CLOSE/READ/WRITE（20h〜23h）だけを使い、生成YKE内のランタイムがDOS指定のword-byteバッファへ変換します。

### バイナリコピー

DOSの正規化後のパスも63文字以内である必要があります。相対パスはカレントディレクトリと先頭の`\`を含めて判定されるため、リテラル自体が63バイトでもエラー206になる場合があります。存在しないファイルのOPENでは、DOSが返すエラー3をそのまま`IORESULT`へ記録します。

同じファイルを入力と出力に指定しないでください。以下はドライブ1の全バイトをコピーし、READ失敗と通常EOFを区別する例です。

```text
program;
var src,dst,ch;
begin
    src := fopen("1:\INPUT.BIN",0);
    if src = 0 then writeln("OPEN ERROR ",ioresult)
    else
    begin
        dst := fopen("1:\OUTPUT.BIN",1);
        if dst = 0 then writeln("CREATE ERROR ",ioresult)
        else
        begin
            ch := fgetc(src);
            while ch >= 0 do
            begin
                if fputc(dst,ch) <> 0 then break;
                ch := fgetc(src);
            end;
            if ioresult <> 0 then writeln("COPY ERROR ",ioresult);
            fclose(dst);
        end;
        fclose(src);
    end;
end.
```

### 文字列と数値の保存

```text
program;
var h;
begin
    h := fopen("RESULT.TXT",1);
    if h = 0 then writeln("OPEN ERROR ",ioresult)
    else
    begin
        if fwriteln(h,"value=",-123," next=",32767) <> 0 then
            writeln("WRITE ERROR ",ioresult);
        fclose(h);
    end;
end.
```

成功時の内容は`value=-123 next=32767`とCRLFです。

## 容量と診断

| 対象 | 上限 |
|---|---:|
| 入力ソース | 8192バイト |
| 識別子 | 31文字 |
| 同時に登録する記号 | 256件 |
| 関数の引数 | 16個 |
| 関数のローカル変数 | 32個とRESULT |
| 構文の入れ子 | 32段 |
| 生成YKEのペイロード | 65520バイト、4バイト整列 |
| ソース行の対応区間 | 2048区間 |

構文の入れ子はBEGIN/IF/WHILE、括弧式、関数とWRITE系の引数解析を数えます。関数の局所記号は本体の解析終了後に取り除きます。NULを含むソースは拒否し、Ctrl+Zはソース終端として扱います。行番号はLFを基準に数えます。

コンパイルエラーは`DULL line n: ...`と表示します。構文、未定義・重複識別子、引数数、ループ外の制御移動、閉じていない文字列、容量、引数、I/Oを区別します。エラー終了コードは1、成功は0です。

生成したプログラムは`DULL: divide by zero`、`divide overflow`、`stack limit`、`console error`を表示してDOSへ戻ります。終了コードは順に1、2、8、5です。正常終了は0です。再帰深さはフレームと式の使用量によって異なり、関数入口でスタックの残量を検査します。

## 出力の保護と復旧

全解析と再配置が成功してから、出力名の拡張子を`.$$$`へ置き換えた一時ファイルを作ります。既存の同名一時ファイルは切り詰めません。出力先の一時ファイルをCLOSEした後、DOSの通常の`MOVE /Y`で目的名へ置き換えます。

構文エラー、容量不足、書込み・CLOSE・移動の失敗では既存の出力を保持します。一時ファイルが作成済みなら`Temporary file kept:`に残したパスを表示します。途中までしか書けていない可能性があるため、自動的に再利用しません。媒体と既存出力を確認し、必要な一時ファイルを退避してから削除し、再コンパイルしてください。

入力、出力、一時ファイルの末尾名が一致する場合は、異なるディレクトリでも保守的に拒否します。同じファイルへの別表記を避けるためです。媒体の故障中や電源断まで含めた保存の原子性は保証しません。

## 原典と移植

本実装はwatara氏のPL/DULL（ひまわり向け）の言語構造をKAPPA上のネイティブ実行へ移植したものです。公開するKAPPA版の文法と動作は本書に記載しています。

原典の字句解析と再帰下降解析をKAPPA ASMへ移し、8086 COMのemit/patchをKAPPA機械語とYKE1へ置き換えています。関数フレーム、文字列、整数入出力、ランタイムを生成物へ含め、既存のDOSコンソール・ファイルAPIだけを使います。

単項負号を識別子・括弧式・関数にも適用する原典実装の挙動を引き継ぎます。負数除算時の原典の符号拡張不備は修正し、エラー後の不完全な出力は公開しません。上記のF系ファイル操作とIORESULTはKAPPA版の独自拡張です。
