# LEDT ラインエディタ

`LEDT filename [/B]` は、DOSの既存ファイルAPIで動くネイティブYKEラインエディタです。指定ファイルがなければ新規編集を始めます。パスはドライブ番号、カレントディレクトリ、サブディレクトリに対応します。名前はDOSの8.3形式、パス全体は63バイト以内です。`.BAK`と`.$$$`のファイルは編集対象にできません。

```text
LEDT MEMO.TXT
```

`*`がコマンド待ちの印です。入力はEnterで確定し、Backspaceで訂正できます。行番号だけを入力するとその行を表示し、次の入力で本文を置き換えます。このとき空のEnterなら元の行を保持します。空行を作るにはIを使います。コマンド待ちで空のEnterを押すと、現在行の次を編集します。

## 行番号と範囲

行番号は1から始まります。`.`は現在行、`+n`と`-n`は現在行からの相対位置、`#`は最終行の次です。範囲の末尾の`#`は最終行までを表します。表示時の`番号:*本文`のアスタリスクは現在行です。範囲は先頭から末尾の順に指定してください。

| コマンド | 動作と省略値 |
|---|---|
| `n` | n行を編集し、現在行にする。省略時は現在行の次 |
| `[n]I` | n行の前に挿入。省略時は現在行。`#I`は末尾。範囲外の大きい位置は末尾へ丸める |
| `[first][,last]D` | 範囲を削除。firstは現在行、lastはfirstが既定。次に残る行、または最終行が現在行になる |
| `[first][,last]L` | 一覧。firstは現在行の11行前（最低1）、lastはfirstの22行後が既定。現在行を保持 |
| `[first][,last]P` | ページ表示。firstは現在行の次、lastはfirstの22行後が既定。表示した最終行が現在行になる |
| `[first],[last],destination[,count]C` | 範囲をdestinationの前へcount回コピー。first/lastは各々現在行、countは1が既定。コピー先の先頭が現在行になる |
| `[first],[last],destinationM` | 範囲をdestinationの前へ移動。first/lastは各々現在行。移動先の先頭が現在行になる |
| `[first][,last][?]Stext` | 大小文字を区別して検索。firstは現在行の次、lastは最終行。見つかった行が現在行になる |
| `[first][,last][?]Rold^Znew` | 全一致箇所を置換。範囲の既定はSと同じ。最後に置換した行が現在行になる |
| `[n]Tfilename` | 別ファイルの全行をn行の前へ挿入。nは現在行が既定。転送先の先頭が現在行になる |
| `[n]A` | 元ファイルの未読部分から最大n行をバッファ末尾へ追加。省略時は75%まで |
| `[n]W` | 先頭n行を一時ファイルへ書き、成功した行をバッファから除く。省略時、またはnが行数を超えると約25%を残す |
| `E` | バッファと元ファイルの未読末尾を保存して終了 |
| `Q` | `Abort edit (Y/N)?`へYで応答すると変更を破棄して終了。その他の応答は編集を継続 |

C/Mのdestinationは必須で、コピー／移動元の範囲内には置けません。Cのcountは正の整数です。省略する項目もカンマは残します。L/Pの末尾は実際の最終行へ丸めます。不正な範囲や容量超過の操作はエラーになり、その操作による本文変更は行いません。Tもファイル全体が収まらなければ、転送前の本文へ戻ります。

Iでは行ごとに`番号:`を表示します。**Ctrl+Zだけの行**をEnterで確定するか、Ctrl+Cを押すと挿入を終えます。挿入終了後は挿入位置の次が現在行になります。

Sのtextを省略すると直前のS/Rの検索文字列を使います。Rのoldも同じ検索文字列を使い、newを省略すると一致文字列を削除します。表中の`^Z`は文字`^`と`Z`ではなく、**実際のCtrl+Z文字**です。置換文字列の末尾にもCtrl+Zを置けます。`?S`と`?R`は一致した行を表示して`O.K.?`で確認します。Yまたは空のEnterで承認、その他の応答でその一致を飛ばします。Rで挿入した文字列を同じ箇所で再検索しません。

## 文字とメモリの上限

本文の文字コードは変換しません。NULを含むバイトもファイル内で保持します。入力のCR、LF、CRLFを行区切りとし、出力はCRLFに統一します。末尾改行のない最終行にもCRLFを付けます。通常は入力ファイルのCtrl+Zで読取りを終え、`/B`ではCtrl+Zも本文のバイトとして保持します。出力にCtrl+Zを自動追加しません。

本文1行は254バイト、コマンドは127バイトです。本文は行長1語を含め12288バイト分、索引は1791行分です。初回とAは本文9216バイト分または1344行まで読みます。次の完全な行が収まらない場合、その行を未読末尾として保持します。編集では残りの容量も使用できます。Wの既定値は、本文3072バイト分かつ448行以下が残るまで先頭行を書きます。行を途中で分割しません。W後は行番号を1から振り直し、最初に残った行が現在行になります。

行長超過やREAD失敗で入力を継続できなくなった場合はEを拒否します。WRITEの一部だけが成功した場合は、完全に保存できた先頭行だけを除去し、その後のW/Eを拒否して重複書込みを防ぎます。元ファイルを保持したまま、Qで終了できます。

Fキーのテンプレート編集、セミコロンで連結した複数コマンド、FreeDOSのカンマ区切り検索文字列は実装範囲に含めていません。コマンドは1行に1つ入力してください。

## 編集例

次は新規MEMO.TXTを作る操作です。`<Ctrl+Z>`はCtrl+Zを押してEnterで確定します。

```text
LEDT MEMO.TXT
I
first
second
<Ctrl+Z>
1,#L
1,1,#,2C
2D
E
```

結果は`first`が3行のファイルです。既存ファイルなら保存前の内容がMEMO.BAKに残ります。

バッファを超えるファイルにはW/Aを組み合わせます。Aはファイル末尾への手入力ではなく、元ファイルの未読部分の読込みです。Wの出力は編集を始めてからの順に一時ファイルへ蓄積します。

```text
LEDT LARGE.TXT
30W
A
30W
A
E
```

Eは残りのバッファと未読部分をすべて出力します。途中までWを実行していても、QでYを選べば元のLARGE.TXTは変わりません。

## 保存と復旧

編集対象と同じディレクトリ、同じ本体名の`.$$$`を一時出力に使います。既存の一時ファイルは上書きしません。既存ファイルのE保存では`.BAK`が存在すると切替前に拒否します。必要な既存BAKを別名へ移してから編集を開始してください。読取り専用の元ファイルも置換できません。

Eは出力と入力をすべて閉じ、通常のMOVEで「元→BAK」「一時→元」の順に切り替えます。2回目のMOVEが失敗すると「BAK→元」で復旧を試みます。切替に失敗した場合は`Recovery paths:`の後に元・BAK・一時のパスを表示します。これらは復旧候補の一覧です。各パスの存在と内容を確認してください。表示だけで全ファイルの存在を保証するものではありません。

通常のQは自分が作った一時ファイルを削除します。WRITE失敗や切替失敗の後は`Temporary file kept:`と表示して一時ファイルを残します。容量不足時には、残る一時ファイルの末尾行が不完全なことがあります。エラー番号8はメモリ不足、19は書込み保護、23は媒体エラー、80は名前の衝突、87は入力形式・行長、112はディスク容量不足を示します。その他の数値はDOSのファイルAPIが返したものです。

例えば元がなくMEMO.BAKとMEMO.$$$が残っていたら、DOSへ戻って内容を確認し、次で元の名前へ復旧できます。

```text
TYPE MEMO.BAK
TYPE MEMO.$$$
MOVE MEMO.BAK MEMO.TXT
```

MOVEは既存宛先を拒否します。確認済みのファイルを別名へ保全してから復旧してください。複数回のMOVE全体について、電源断に対する原子性は保証しません。

行コマンドの基準資料：[Microsoft Press, The MS-DOS Encyclopedia — EDLIN](https://www.pcjs.org/documents/books/mspl13/msdos/encyclopedia/section3/)。BAK衝突の拒否、Ctrl+Z行による挿入終了、容量値と復旧時の一時ファイル保持はLEDTの仕様です。
