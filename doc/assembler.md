# アセンブラマニュアル

`yosic-as`は、アセンブリ言語で書いたテキストをYOSIC-KAPPAの命令バイト列へ変換します。この変換を「組み立て」と呼びます。
Alfred ArnoldのMacroassembler ASを参考にした整数式とマクロを使えます。対応範囲は本書に記載した機能です。
実行方法は[エミュレータ](emulator.md)、命令の正確な動作は[アーキテクチャ](architecture-reference.md)、機器の使い方は[インターフェース](interface-reference.md)を参照してください。

## 1. 最初のプログラム

実行用フォルダのルートをcmdで開き、新しい`work`フォルダを作っておきます。
次の3行をUTF-8のテキスト`work\first.asm`として保存してください。

```asm
        ADI R1,RZR,5
loop:   ADI R1,R1,1
        JMP loop
```

最初の命令でR1へ5を入れます。次の命令で1を足し、最後の命令で足し算へ戻ります。

```bat
bin\yosic-as.exe work\first.asm -o work\first.rom --list work\first.lst --map work\first.map
bin\yosic-sim.exe --rom work\first.rom --steps 4 --registers
```

4命令後は`R1=0x7`になります。生成される12バイトは`05 00 2f 44 01 00 21 44 ff ff 1f 18`です。
アセンブラは成功時に本文を表示せず、終了コード0を返します。実行の診断はstderrに出ます。

## 2. 入力と出力

構文は`yosic-as INPUT -o OUTPUT [--base ADDRESS] [--list FILE] [--map FILE] [-I DIR ...]`です。

| 引数 | 用途 |
|---|---|
| `INPUT` | 最大16 MiBのソースを1ファイル指定 |
| `-o OUTPUT` | 命令・データのバイナリ。必須 |
| `--base ADDRESS` | ソース内アドレスの起点。既定0、64 KiB整列の32ビット値 |
| `--list FILE` | 生成バイト、アドレス、原文、元のファイルと行番号を保存 |
| `--map FILE` | ラベルや定数の値を保存 |
| `-I DIR` | INCLUDE/BINCLUDEの検索先。繰り返し指定可 |
| `--help` | 単独で使い、使い方を表示 |

CLIのbaseは10進か`0x`付き16進です。ソースの数値構文とは異なります。
出力はbaseから最大64 KiBです。未使用の隙間は0で埋め、同じ場所への重複書込みは拒否します。
ROMの物理位置をソースに書く場合は`--base 0xff0000`を指定します。baseは出力ファイルの先頭に巨大な余白を作る設定ではありません。
命令の位置は4バイト整列が必要です。データだけの出力は任意の長さになり得ますが、ROMローダは4バイトの倍数を要求します。

出力先の親フォルダは先に作ります。**成功した組立てでは既存出力を上書きします。** 入出力の同一パス、大小文字だけが違う同一パス、hardlinkで同じファイルを指す出力は拒否します。
構文・展開エラーは出力前に検査するため、既存出力は変わりません。すべての出力を一時ファイルへ書き終えてから置き換えます。通常のI/Oエラーでは既存出力を戻します。復元自体がOSのエラーで失敗した場合は、退避ファイルの場所を診断に表示します。
終了コードは0=成功、2=構文・引数の誤り、3=入出力の失敗です。

## 3. 行、ラベル、コメント

ラベルは、命令やデータの位置に付ける名前です。

```asm
        CPU YOSIC-KAPPA
Console EQU 0FEh
        ADI R0,RZR,Console
entry:  NOP
.loop   JMP .loop
        END
```

命令、レジスタ、記号名の大文字と小文字は区別しません。mapには大文字の記号名を出します。
記号は英数字、`_`、`.`で最大255文字です。数字では始められません。
行の1列目に置くラベルはコロンを省略できます。インデントしたラベルにはコロンを付けます。
既知の命令や疑似命令は1列目でも使えます。命令と同じ名前をラベルにするときはコロンを付けてください。
`.loop`のような名前は、直前のグローバル記号と結び付くローカル記号です。上の例では`ENTRY.LOOP`になります。
`;`から行末まではコメントです。ただし引用符で囲んだ文字列の中の`;`と`,`は文字として扱います。

## 4. 命令とオペランド

オペランドは命令が使うレジスタ、数値、場所などです。レジスタは`R0`～`R15`、別名は`SP`=R14、`RZR`=R15です。
セグメント名は`CS`、`DS`、`SS`、`ES`です。

| 構文 | 主な用途 |
|---|---|
| `NOP` | 何もしない |
| `LRM Rd,[Rb+imm]` | DS側のメモリから4バイト読む |
| `SRM Rs,[Rb+imm]` | DS側のメモリへ4バイト書く |
| `PSH Rs` / `POP Rd` | スタックへ保存／スタックから取出し |
| `SRZ Rs` / `SNZ Rs` | 値が0／非0なら次の1命令を飛ばす |
| `JMP target` | 指定したラベル・アドレスへ分岐 |
| `ADD Rd,Ra,Rb` / `ADI Rd,Ra,imm` | レジスタ／即値を加算 |
| `SUB Rd,Ra,Rb` | 減算 |
| `ANL Rd,Ra,Rb` / `ORR Rd,Ra,Rb` / `XOR Rd,Ra,Rb` | ビットごとのAND／OR／XOR |
| `LSEG Seg,Rs` | セグメントへRsの下位16ビットを設定 |

`imm`は符号付き16ビット、-32768～32767です。メモリ指定には`[R2]`、`[R2+4]`、`[R2-4]`を使えます。
JMPには相対値ではなく目的地を書きます。アセンブラが現在命令からの差を4で割り、符号付き21ビットの相対値へ変換します。
目的地はbaseから64 KiBの同じセグメント内で、4バイト整列が必要です。
FLAGS、桁あふれ、faultの詳細は[命令仕様](architecture-reference.md#全15命令)で確認できます。

## 5. 整数と式

即値や定数には計算式を使えます。通常は10進、`0FFh`・`101b`・`17o`・`17q`のIntel接尾辞、`0xFF`・`0b101`の接頭辞に対応します。
Intel形式で最初の桁がA～Fになる場合は、先頭に0を付けます。`TRUE`は1、`FALSE`は0です。
`RELAXED ON`では`$FF`・`%101`・`@17`、`x'FF'`・`h'FF'`・`b'101'`・`o'17'`、先頭0の8進数も使えます。`RELAXED OFF`で通常へ戻します。
通常の`077`は77、RELAXED ONの`077`は63です。
`$`は現在位置です。RELAXED ONで直後に16進数字を置くと数値リテラルになる点に注意してください。

演算子の優先順位は**次の表の上ほど強く**、同順位の二項演算子は左から計算します。C言語の優先順位とは異なります。

| 演算子 | 意味 |
|---|---|
| `~` | ビット反転 |
| `~~` | 論理否定 |
| `<<` `>>` | 左シフト／符号を保つ右シフト |
| `><` | 下位1～32ビットを指定して順序を逆転 |
| `&` | ビットAND |
| `\|` | ビットOR |
| `!` | ビットXOR |
| `^` | べき乗 |
| `*` `/` `#` | 乗算／整数除算／剰余 |
| `+` `-` | 加減算・単項符号。単項+も使用可 |
| `&&` | 論理AND |
| `\|\|` | 論理OR |
| `!!` | 論理XOR |
| `=` `==` `<>` `!=` `<` `>` `<=` `>=` | 比較。結果は0か1 |

`1+2<<3`は17、`2^3`は8、`5!3`は6、`2^3^2`は64、`-2^2`は-4になります。意図が伝わりにくい式には括弧を付けます。
`&&`と`||`は結果が決まれば残りの値を評価しません。ただし式の構造は検査します。
中間値は符号付き64ビットです。加減乗算とべき乗の桁あふれ、ゼロ除算はエラーです。
シフト数は0～63です。負の整数を指数とするべき乗の結果は0です。最終値が格納先の幅に収まることも検査します。

単引用符と二重引用符で文字列を囲みます。整数の場所では1～4バイトを上位側から詰めます。`'AB'`は`0x4142`です。
文字列はUTF-8の入力バイトを保ち、NULも使えます。文字コード変換はありません。
エスケープには`\a \b \e \t \n \r`、`\' \"`（別名`\H \I`）、`\\`を使えます。文字形式の名前は大小文字を区別しません。
数値エスケープは10進で最大3桁、先頭0なら8進で最大3桁、`\x`は16進で最大2桁です。

## 6. 定数、配置、データ

疑似命令はアセンブラへ指示を出す行です。CPUが実行する命令ではありません。

| 疑似命令 | 意味 |
|---|---|
| `Name EQU expr` / `Name = expr` / `EQU Name,expr` | 再代入できない整数定数 |
| `Name SET expr` / `Name EVAL expr` / `Name := expr` | 再代入できる整数。既存EQUやラベルには代入不可 |
| `Name LABEL expr` | 指定値のグローバルラベル。マクロ内でも公開される |
| `Name FUNCTION a,b,expr` | 整数関数。`Name(x,y)`で呼び出す |
| `ORG address` | baseの範囲内で配置先を指定 |
| `ALIGN n[,fill]` | n=1～65536の倍数まで埋める。fill=-128～255、省略時は0 |
| `DB value,...` | -128～255の値、または文字列の全バイト |
| `DW value,...` | -32768～65535の16ビット値 |
| `DD value,...` | -2147483648～4294967295の32ビット値 |
| `DS.B n` / `DS.W n` / `DS.L n` | n×1／2／4バイトを0で確保 |
| `CPU YOSIC-KAPPA` | CPU名を検査 |
| `END` | 以降のソース処理を終了 |
| `RELAXED ON` / `RELAXED OFF` | 数値リテラルの拡張を切替え |

DW/DDは下位バイトから並べます（little-endian）。非整列位置にも置けますが、CPUの命令とアクセスには4バイト整列が必要です。
EQUの`$`は定義した行の位置です。同じデータ行の各値から見える`$`は、すべてその行の開始位置です。
SETは使用行の値を使います。後のSETで前の行やEQUの値は変わりません。FUNCTIONからSETを参照する場合も同じです。
ORG、ALIGN、領域の確保数、条件、繰返し数は、その行に達した時点で評価できる必要があります。
通常の命令・データ値・EQUは、後に書いたラベルや定数を参照できます。循環参照はエラーです。

次を`work\data.asm`へ保存して組み立てると、式の結果をバイト列で確認できます。このファイルはデータ専用で、ROMとして実行しません。

```asm
        CPU YOSIC-KAPPA
Twice   FUNCTION x,x*2
Value   SET 3
Fixed   EQU Value
        DB 1+2<<3,5!3
        DW 'AB'
        DD Twice(Value)
Value   SET 7
        DB Fixed,Value
        ALIGN 4,0
        DS.L 1
        END
```

```bat
bin\yosic-as.exe work\data.asm -o work\data.bin --list work\data.lst
```

出力は`11 06 42 41 06 00 00 00 03 07 00 00 00 00 00 00`です。
旧構文の`.equ NAME,expr`、`.org`、`.align`、`.space`、`.byte`、`.word`、`.ascii`も受理します。
旧`.word`は**32ビットかつ4バイト整列**で、16ビットのDWとは異なります。旧`.equ`では`$`を使えず、旧`.align`は2のべき乗だけです。
旧`.space n`はnバイトの0、`.ascii "text"`は文字列のバイト列、`.byte`は8ビット整数を出します。領域の確保数nは0以上で、全出力の64 KiB以内に収めます。

## 7. マクロ

マクロは名前を付けて繰り返し使うソースです。呼出しより前にMACROで定義し、ENDMで閉じます。
次を`work\macro.asm`へ保存します。

```asm
Inc     MACRO reg,count=1
        REPT count
        ADI reg,reg,1
        ENDM
        ENDM
        Inc R1,3
        Inc count=2,reg=R2
stop:   JMP stop
```

```bat
bin\yosic-as.exe work\macro.asm -o work\macro.rom --list work\macro.lst
bin\yosic-sim.exe --rom work\macro.rom --steps 5 --registers
```

`R1=0x3`と`R2=0x2`になります。引数名は英字で始まる英数字です。
位置引数と`name=value`のキーワード引数を使えます。キーワード引数の後に位置引数は置けません。
省略または空の位置引数には既定値を入れます。既定値がなければ空文字です。`name=`は明示的な空文字になります。
余った実引数はALLARGSやSHIFTで扱えます。文字列の中でも引数を置換します。その場合は仮引数名を**大文字**で書きます。
`part1_part2`のようにアンダースコアを挟んで引数を結合できます。

| 機能 | 意味 |
|---|---|
| `ALLARGS` / `ARGCOUNT` | 現在の実引数列／個数。呼出し時は仮引数数まで補う |
| `ATTRIBUTE` | 呼出し名に付けた`.B`などの属性の文字列 |
| `{INTLABEL}` / `__LABEL__` | 呼出し行のラベルを本体で扱う。既定では呼出し先頭の位置にラベルを定義 |
| `{GLOBALSYMBOLS}` | 本体のラベルを外へ公開 |
| `{NOGLOBALSYMBOLS}` / `{NOINTLABEL}` | 対応する設定を解除 |
| `SHIFT` | 実行中マクロの先頭引数を捨てて残りを左へ移動 |
| `EXITM` | 一番内側のマクロ・反復ブロックを抜ける |
| `MAXNEST n` | 展開深度。既定64、範囲1～256 |
| `!NOP`など | 同名マクロを避け、機械命令・通常指示を使う |

通常の本体ラベル、新しいEQU/SETは展開ごとの局所名になります。繰返しでも毎回別の名前です。
すでにあるSETの更新は外側の変数へ作用するため、WHILEの制御に使えます。LABELは局所化せず公開します。
マクロや反復の入れ子、再帰呼出しに対応します。マクロ内で定義したマクロもアセンブリ全体の名前空間に入り、同じ定義を繰り返すとエラーです。

## 8. 繰返しと条件

| 構文 | 展開する条件 |
|---|---|
| `IRP arg,v1,v2,...` ～ `ENDM` | 各値を順にargへ入れる |
| `IRPC arg,"text"` ～ `ENDM` | 各バイトを順にargへ入れる |
| `REPT count` ～ `ENDM` | count回。0以下なら0回 |
| `WHILE expr` ～ `ENDM` | 式が非0の間 |
| `IF expr` / `IFDEF name` / `IFNDEF name` | 値が真／定義済み／未定義の分岐 |
| `ELSEIF expr` / `ELSE` / `ENDIF` | 次の条件／それ以外／条件の終わり |

条件には整数式か、引用した2つの文字列の直接比較を使えます。空文字も比較できます。
引数なしELSEIFはELSEとして扱います。選ばない分岐の式や命令は実行しません。
EXITMで抜けると、未到達のENDIFを要求せず、呼出し側の条件状態へ戻ります。
反復本体は外側の引数を一度置換してから繰り返します。反復中にSHIFTしても、すでに取り込んだ引数の文字列は変わりません。

展開作業は10万ステップ、展開テキストは16 MiB、1展開行は1 MiBまでです。式の入れ子は128、FUNCTIONの呼出しは64までです。
MAXNEST 0で制限を解除することはできません。WHILEで停止しない場合は、制御変数の更新を確認します。

## 9. コンソール表示とIPL

同梱の小さいマクロ例は`AS`と表示します。

```bat
bin\yosic-as.exe src\examples\macro-console.asm -o work\console.rom
bin\yosic-sim.exe --rom work\console.rom --steps 12
```

仕組みは[macro-console.asm](../src/examples/macro-console.asm)で確認できます。DSを`0xFE`にして、コンソールのTX_DATAへ書き込みます。
IPLとstage2の全ソースは[ipl.asm](../src/firmware/ipl/ipl.asm)と[stage2.asm](../src/firmware/stage2/stage2.asm)です。
組立てから媒体作成と起動までは[エミュレータの手順](emulator.md#7-iplとstage2を作り直す)を使います。
stage2の配置先とレジスタの初期値は[IPL契約](interface-reference.md#ipl契約)に従います。

## 10. リスティングとシンボルマップ

最初の例の`first.lst`は次の内容になります。

```text
YOSIC-KAPPA Assembler Listing v1
    Line M   Address Object bytes            Source
       1    00000000 05 00 2F 44                     ADI R1,RZR,5 ; @first.asm:1
       2    00000004 01 00 21 44             loop:   ADI R1,R1,1 ; @first.asm:2
       3    00000008 FF FF 1F 18                     JMP loop ; @first.asm:3
```

行番号、印、アドレス、生成バイト、原文を列で並べます。バイトはメモリに置く順で、1行に8バイトまでです。
続くバイトは`+`行へ出し、その行の先頭アドレスを示します。原文は最初の行だけに置き、長いコメントも省略しません。
原文のタブは8文字単位の空白に展開します。列の接頭辞は45文字で、ソースは46列目から始まります。
アドレスは通常8桁の大文字16進です。画像の終端が`100000000`になる場合も省略せず9桁を表示します。

| 印 | 意味 |
|---|---|
| 空白 | 通常のソース行 |
| `+` | 同じ行から生成したバイトの続き |
| `D` | マクロ定義や反復の本体。まだ組み立てていない原文 |
| `C` | 呼出し、反復、条件、INCLUDE、ENDなどの制御 |
| `E` | マクロや反復から展開されたコード |
| `-` | 条件不成立やEND/EXITM後で実行しない行 |

`@file:line`は定義元のファイルと行、`via`は呼出し元の経路です。
たとえば`main.asm:4/REPT#2 > main.asm:5/EMIT#1`は、4行目の反復の2回目から5行目のEMITを呼んだことを示します。
展開行には引数や局所名を置換したコード、D行には定義の原文が残ります。INCLUDE内の行も元ファイル名で追えます。
ファイル名の自動注記は主ソースのフォルダからの相対名です。別ドライブの参照はファイル名のみになるため、同名ファイルはINCLUDE行も確認してください。

コメント、空行、ラベルだけの行、CPUやENDも残ります。生成しない行ではバイト欄が空です。
EQU/LABELには`value=`、SETにはその行での値、FUNCTIONには`function`が付きます。
ORGには移動先を表示します。末尾の`zero-fill`は実際の出力で0補完した未使用範囲で、命令のバイトとは別です。
ALIGN/DS/BINCLUDEの実データは継続行で示します。最大64 KiBなら8192行のバイト表示になります。

形式は`v1`、UTF-8、LF改行です。日時は入りません。同じソース・依存ファイル・指定から同じ内容を生成します。
旧形式の「連続したバイト列と`; line N`」はこの列形式へ置き換わりました。ASの出力と完全一致する形式ではありません。
mapのラベルは`LOOP = 0x4`の形、定数は10進値で出ます。記号名は大文字です。mapの形式と値は従来通りです。

### ファイルを取り込む

`INCLUDE file`はソース、`BINCLUDE file[,offset[,length]]`はバイナリの内容を取り込みます。
ファイル名は定数で、空白を含むときは引用符で囲みます。引用符の中のWindowsの`\`はそのまま区切りとして使えます。
INCLUDEは拡張子を省くと`.inc`を補います。BINCLUDEのファイル名は補いません。

相対パスは命令を書いたファイルのフォルダが基準です。マクロ内なら定義元を使います。
裸のファイル名がそこで見つからないときだけ、`-I DIR`を指定した順に探します。パス付きの指定では検索先を使いません。
INCLUDE先は記号とマクロを共有しますが、IF/ENDIFやMACRO/ENDMなどの組は各ファイル内で閉じてください。
不成立の条件や呼び出さないマクロ内のファイルは開きません。ENDは組立て全体を終了します。
循環参照はエラーです。主ソースを含む同時参照は64ファイルまで、読み込む内容の合計は16 MiBまでです。

BINCLUDEのoffsetとlengthは、その行で値が決まる非負整数式です。offset省略は0、length省略はファイル末尾までです。
ファイル外の範囲と画像全体の64 KiB超過はエラーです。EOF位置から0バイトを取る指定と空ファイルは使えます。
入力したバイナリのバイト順や改行は変えません。取り込んだ全ファイルも出力先との重複検査の対象になります。

次を`work\constants.asm`へ保存します。

```asm
Size EQU 12
```

次を`work\included.asm`へ保存します。最初の例の`first.rom`から4バイト取り込みます。

```asm
        INCLUDE "constants.asm"
        DB Size
        BINCLUDE "first.rom",0,4
```

```bat
bin\yosic-as.exe work\included.asm -o work\included.bin --list work\included.lst
```

結果は`0C 05 00 2F 44`の5バイトです。

## 11. エラーを直す

まず終了コードと`error: line N`と`ファイル名:行番号`を確認します。マクロの失敗では呼出し経路も確認します。
即値が大きすぎる場合は符号付き16ビットの範囲を確認します。JMPのエラーでは目的地とbase、4バイト整列を確認します。
入出力パスが重なった場合は、別の出力名を指定してください。

次のエラー例は`work\bad.asm`へ保存します。

```asm
        NOP 1
```

```bat
bin\yosic-as.exe work\bad.asm -o work\first.rom
```

終了コード2と行1の診断が出ます。先に作った`first.rom`の内容は変わりません。

深い再帰マクロにはWindowsのスタック上限による既存の制約があります。無限再帰は既定のMAXNEST診断より先に終了する場合があるため、再帰の終了条件を設け、調査時は`MAXNEST 8`など低い値で確認してください。

## ASとの対応範囲

| 分類 | 対応 |
|---|---|
| 整数式・基本文法 | 本書の演算子、ラベル、定数、データ、文字列、FUNCTION |
| マクロ | MACRO、反復、条件、引数、局所名、SHIFT、EXITM |
| ファイル取込み | INCLUDE、BINCLUDE（本書の検索規則と制限） |
| 数値モード | Intel/C形式を併用する本実装の既定値。ASのCPU別既定値とは異なる |
| 互換拡張 | 単項+、列1の既知命令、旧ドット構文 |
| 未対応 | SECTION、PUBLIC、GLOBAL、STRUCT、SWITCH、マクロのリスト制御 |
| 未対応の式など | 浮動小数、一般の文字列演算・関数、組込み数学関数、RADIX、名前合成`{...}`、`$$`、無名一時ラベル、DUP、`?`による未初期化領域 |

未知の指示や制御オプションはエラーです。他CPU用のASソースをそのまま組み立てる機能はありません。
整数式の根拠はMacroassembler ASの`operator.c`と`asmpars.c`、リビジョン`c7155b4fd3d33110f0eb098dede4295a8c008772`です。
右シフトは符号を保つ実装に合わせています。ASの全機能や全入力の互換性を保証するものではありません。

用語: 記号=ラベルや定数の名前、即値=命令内の数値、展開=マクロなどを実際のソース行へ置換する処理、整列=アドレスを指定の倍数に合わせることです。
