# ハードウェアモニタ・デバッガ

エミュレータのコンソール上で動くハードウェアモニタです。CPU、レジスタ、メモリ、FDC、4台のドライブの状態を表示し、SYMDEB形式のコマンドでデバッグします。

## 起動と停止

端末から起動すると、モニタを表示して実行開始前に停止します。`-`がモニタの入力プロンプトです。`G`を入力するとIPLとDOSが動き始め、DOS起動後は`0:>`でDOSのコマンドを入力できます。

ゲスト実行中にCtrl+Breakを押すとモニタへ戻ります。`G`で続行、`T`で1命令実行、`Q`でエミュレータを終了します。対話実行中のCtrl+Cはゲストへ渡し、DOSでは媒体状態をリセットします。モニタ停止中のCtrl+Cは終了です。停止時にはCPUとハードウェアの状態を表示します。

明示する場合は`--monitor`、モニタを使わず直接ゲストを起動する場合は`--no-monitor`を指定します。入力ファイルまたはパイプから実行する場合、既定ではモニタを使いません。明示した`--monitor`には実端末が必要で、`--input`とは併用できません。DOSの手入力には通常どおり`--interactive`も必要です。

CPU・バスのfaultはモニタを使っている場合、その場所で一時停止し、内容を表示します。PCやメモリを修正して再開できます。モニタを使わない場合は通常のfault終了になります。QやCtrl+Cで終了すると、指定済みのディスク保存先へ書き込みます。

## 文法

CPUデバッグのコマンド名と引数の配置はMicrosoftの[SYMDEBの仕様](https://msarchive.pcjs.org/mspl13/msdos/encyclopedia/section4/)に合わせています。以下の基本コマンドに対応します。媒体管理は[SIMHのATTACH/DETACH](https://simh.trailing-edge.com/pdf/simh_doc.pdf)に相当する機能を`AT`・`DT`として提供します。表にないコマンドは受け付けません。

- 数値は16進です。`10`は16、`10H`も16です。大小文字は区別しません。引数は空白またはカンマで区切ります。
- アドレスは`セグメント:オフセット`です。`CS:0100`、`DS:4000`、`0008:0000`のように指定します。
- KAPPAでは物理アドレスは`(セグメント << 16) + オフセット`です。両方とも16ビットで、x86とはアドレス換算が異なります。
- データ操作の省略セグメントはDS、実行・逆アセンブル・ブレークポイントはCSです。DとUは前回明示したセグメントと続きのアドレスを保持します。
- 範囲は`開始 終了`（終了を含む）または`開始 L 長さ`です。`L10`のようにも書けます。DBの長さはバイト数、DWは16ビット項目数、DDは32ビット項目数、Uは命令数です。1回の表示は最大4096項目です。
- レジスタ名は`R0`〜`R15`、`SP`、`RZR`、`CS`、`DS`、`SS`、`ES`、`PC`、`IP`、`F`、`FLAGS`です。SPはR14、RZRはR15、IPはPC、FはFLAGSの別名です。RZRは変更できません。

## コマンド一覧

| 書式 | 動作 |
|---|---|
| `? [value]` | 引数なしで対応コマンドのヘルプ。数値やレジスタを指定すると値を表示 |
| `R` | 一時停止し、全レジスタと現在の命令を表示 |
| `R register [[=] value]` | レジスタを表示・変更。値を省略すると`:`で入力を促す。空のEnterで変更を取り消す |
| `D [range]` | 前回と同じ形式でメモリを表示。初回はDB形式、DS:0000から |
| `DB [range]` | バイト単位で表示 |
| `DW [range]` | 16ビット単位で表示 |
| `DD [range]` | 32ビット単位で表示 |
| `E address [list]` | 前回と同じ形式でRAMへ入力。初回はEB形式 |
| `EB/EW/ED address [list]` | バイト／16ビット／32ビット値を入力。値の省略時は入力を促す。空のEnterで取り消す |
| `U [range]` | KAPPAの全15命令を逆アセンブル。引数省略時は8命令、次回はその続き |
| `G [=address] [breakpoints]` | 実行を再開。開始位置を指定する場合は`=`が必要。一時ブレークポイントは最大10個 |
| `T [=address] [count]` | 指定命令数を実行して停止。省略時は1命令 |
| `P [=address] [count]` | Tと同じ進行単位で、標準Callマクロの先頭では呼出し全体を実行して復帰位置で停止 |
| `BP[n] address [passcount]` | 継続ブレークポイントを設定。番号0〜9はBPに続ける。省略時は空き番号を使用 |
| `BL` | 継続ブレークポイントの一覧 |
| `BC n` / `BC *` | 指定番号／すべての継続ブレークポイントを削除 |
| `BD n` / `BD *` | 指定番号／すべてを無効化 |
| `BE n` / `BE *` | 指定番号／すべてを有効化 |
| `AT` | 4台の媒体の接続状況・ファイル名を表示 |
| `AT [-R] [-E] drive filename` / `ATTACH` | ディスクイメージを接続・差し替え |
| `DT drive` / `DT ALL` | 指定ドライブ／すべての媒体を取り外す |
| `Q` | エミュレータを終了 |

Gの一時ブレークポイントは停止時に消えます。BPは削除または無効化するまで残ります。passcountは停止まで通過する回数です。命令・ブレークポイント・PCは4バイト整列が必要です。T/PのcountとBPのpasscountはFFFF以下、T/Pのcountは1以上です。

E系のlistは数値の列です。RAMへの変更に限り、ROMやMMIOの変更は拒否します。表示は非破壊のpeekを使うため、コンソール入力やFDCの結果バイトを消費しません。D/DB/DW/DDで指定した先頭を、次に停止したときのメモリ表示にも反映します。

SYMDEBの式計算、文字列入力、ソース行・シンボル、ブレークポイントへのコマンド文字列指定には対応していません。KAPPAにはCALL命令がないため、Pは公開ランタイムの`LRM R2,[R12+変位]; PSH R2; JMP; DD 復帰命令`というCall展開を認識します。それ以外の命令ではTと同様に1命令ずつ進みます。

## ディスクイメージの差し替え

ゲスト実行中はCtrl+Breakでモニタへ戻り、次のように操作します。ドライブは0〜3（またはFD0〜FD3）です。空白を含むホスト側のパスは二重引用符で囲みます。相対パスはエミュレータを起動したフォルダが基準です。

```text
AT 0 "boot\other.d88"
AT
DT 1
G
```

D88、rawの.img、KFDに対応します。D88は先頭の媒体を使用します。rawと新規媒体は起動時の`--geometry`を使い、省略時は80シリンダ・2ヘッド・18セクタ・サイズコード2（512バイト/セクタ）です。SIMHのATTACHを基準に、ATは既定で読書き接続し、同じイメージへ変更を保存します。`-R`は読取り専用、`-E`は既存ファイル限定です。既定では存在しないファイルに指定形状の媒体を新規作成します。ホスト側で書込み不可なら読取り専用で接続します。`AT`一覧の `[read/write]` / `[read-only]` を確認してください。

新しい媒体の読込み・検査が失敗した場合は、元の接続を維持します。ATで読書き接続した媒体の変更は交換・取り外し・終了時に同じイメージへ保存します。変換を検査してから一時ファイル経由で置き換え、保存失敗時は元の接続と変更データを維持します。同じファイルを複数ドライブへ書込み接続することは拒否します。旧媒体に`--disk-copy`で別の保存先が指定されている場合は従来どおりその新規ファイルへ保存し、旧保存先を新媒体へ引き継ぎません。物理FORMAT後の回転配置を保持するにはKFDを使用してください。D88/rawへ損失なく保存できない場合はエラーになります。

[SIMH Users’ Guide](https://simh.trailing-edge.com/hp/docs/simh_doc.pdf)のATTACH規約に従う既定RWと-R/-Eを実装しています。-Nによる既存ファイル切詰めなどの全スイッチ互換は対象外です。

FDCのコマンド・転送・結果受取り・対象ドライブのseek中は交換を拒否します。操作をGで完了させ、再度Ctrl+Breakで戻ってください。DOSの処理全体を保護する交換ロックはありません。

媒体はDOSのプロンプト待ちで交換し、`G`で戻ってからCtrl+Cを押してください。DOSはCP/M 2.2を参考にルートディレクトリの128バイト単位のチェックサムを比較し、不一致を検出したドライブを読取り専用にします。Ctrl+Cで全ドライブのログイン状態、FAT・ディレクトリキャッシュ、現在位置とハンドルをリセットし、ドライブ0を選択します。媒体交換だけでは自動的にリセットしません。チェックサムが同じ媒体の交換は検出できません。FAT12のサブディレクトリはこの交換検出の対象外です。


## 使用例

`-`プロンプトで実行します。

```text
R
DD 0000:4000 L10
U CS:0000 L8
R R1=12345678
ED 0000:4000 DEADBEEF
T
BP0 0002:0000
BL
G
BC 0
Q
```

停止時のFDC表示は処理段階、MSR、IRQ、DRQを示します。各ドライブには媒体の有無、モーター、準備状態、書込み保護、シリンダ位置を表示します。仮想時刻はエミュレータ内の時刻であり、Windows上の経過時間ではありません。
